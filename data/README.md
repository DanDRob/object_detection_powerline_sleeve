# Data Directory (`data/`)

This directory contains all the data used and generated by the powerline sleeve detection project.

## Structure

- `routes.csv`:

  - **Purpose**: Defines the geographical routes for which images should be acquired by the `src/acquisition` module.
  - **Format**: CSV file with the following required columns:
    - `route_id`: A unique string identifier for each route (e.g., "001", "004").
    - `start_location`: The starting point of the route. Can be an address or a "latitude,longitude" string (e.g., "617 Eglinton Ave E, Toronto, ON" or "43.7090,-79.3801").
    - `end_location`: The ending point of the route, in the same format as `start_location`.
  - **Used By**: `src.acquisition.acquisition_run`

- `raw/`:

  - **Purpose**: Stores the raw street-level images downloaded directly from the Google Street View API by the `src/acquisition` module.
  - **Contents**: JPEG images.
  - **Naming Convention**: `pl_r<route_id>_p<point_index>_<side>_h<heading>_p<pitch>_fov<fov>.jpg` (e.g., `pl_r004_p15_right_h90_p30_fov55.jpg`).
  - **Generated By**: `src.acquisition.acquisition_run` (via `src.acquisition.streetview_client` or `src.acquisition.image_processor`).
  - **Configurable Path**: The exact path is defined in `config.yaml` under `paths.raw_images`.

- `labeled/`:

  - **Purpose**: Intended to store images after they have been labeled (either manually or automatically) with bounding boxes for powerlines and sleeves. Often contains corresponding label files (e.g., XML, JSON, TXT) alongside the images.
  - **Contents**: Image files (likely copied/symlinked from `raw/`) and associated label files.
  - **Generated By**: Labeling tools/processes (defined in `src/labeling`).
  - **Configurable Path**: Defined in `config.yaml` under `paths.labeled_images`.

- `processed/`:

  - **Purpose**: Stores the final, processed datasets ready for model training. This typically involves splitting the labeled data into training, validation, and test sets, possibly applying augmentations, and formatting the data as required by the model (e.g., YOLOv8 format with specific directory structure and `.yaml` file).
  - **Contents**: Organized image and label files (e.g., `train/images/`, `train/labels/`, `val/images/`, etc.) and dataset definition files (e.g., `data.yaml`).
  - **Generated By**: Dataset preparation scripts (defined in `src/dataset`).
  - **Configurable Path**: Defined in `config.yaml` under `paths.processed_dataset`.

- `cache/` (Optional, location configurable):
  - **Purpose**: Stores cached images downloaded by the `src/acquisition` module to avoid redundant API calls.
  - **Generated By**: `src.acquisition.cache_manager`.
  - **Configurable Path**: Defined in `config.yaml` under `acquisition.cache_dir` (e.g., `data/cache`).

**Note**: The exact locations of these subdirectories can be configured in the main `config.yaml` file in the project root.

## Directory Structure

```
data/
│
├── powerlines/             # Powerline detection dataset
│   ├── original/           # Original powerline images and labels
│   │   ├── images/         # Original images
│   │   └── labels/         # Original labels in YOLO format
│   │
│   └── augmented/          # Augmented powerline images and labels
│       ├── images/         # Augmented images with _aug_N suffix
│       └── labels/         # Augmented labels with _aug_N suffix
│
├── sleeves/                # Sleeve detection dataset
│   ├── original/           # Original sleeve images and labels
│   │   ├── images/         # Original images
│   │   └── labels/         # Original labels in YOLO format
│   │
│   └── augmented/          # Augmented sleeve images and labels
│       ├── images/         # Augmented images with _aug_N suffix
│       └── labels/         # Augmented labels with _aug_N suffix
│
├── datasets_original/      # Original datasets (for reference)
├── raw/                    # Raw (unprocessed) images
├── labeled/                # Manually labeled images
├── processed/              # Processed datasets
└── cache/                  # Cache directory for image acquisition
```

## Usage

### Dataset Organization

1. Place original powerline images in `powerlines/original/images/`
2. Place original powerline labels in `powerlines/original/labels/`
3. Place original sleeve images in `sleeves/original/images/`
4. Place original sleeve labels in `sleeves/original/labels/`

### Data Augmentation

Use the `scripts/augment_dataset.py` script to augment the datasets:

```bash
# Augment powerlines dataset
python scripts/augment_dataset.py --dataset powerlines --num-augmentations 3

# Augment sleeves dataset
python scripts/augment_dataset.py --dataset sleeves --num-augmentations 3
```

This will create augmented versions of the images and labels with suffixes like `_aug_1`, `_aug_2`, etc.

## Naming Convention

- Original images and labels use their original filenames
- Augmented images and labels have the format: `original_filename_aug_N.ext` where N is the augmentation number
